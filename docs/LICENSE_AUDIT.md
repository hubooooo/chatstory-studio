# License audit — 2026-11-07

Status: original source can be offered under MIT, **subject to independent dependency conditions**. This is not a blanket “all dependencies permissive” conclusion.

Both requested repositories lacked actual license files at inspected commits. README MIT text was insufficient for copying. None of their code/assets was copied, so this uncertainty does not block distribution of our independent implementation. Preserve this provenance instead of implying we forked a licensed codebase.

Actual installed licenses were read, direct texts copied and npm metadata inventoried with `npx tsx scripts/notices.ts`. Remotion's custom license restricts eligibility and relicensing of Remotion derivatives. We use unmodified packages through their public APIs for video creation. The source archive excludes node_modules, Chromium, FFmpeg/FFprobe binaries and Python environments. Do not market the product as free for organizations regardless of size. No automatic purchase occurs.

The initially evaluated `edge-tts-universal` library has AGPLv3 text. It was removed and replaced with an independently written adapter invoking the separately installed LGPL Python edge-tts CLI. No code from either implementation was copied. The current dependency lock has no edge-tts-universal package. Historical experimental imports are provenance, not included library code.

Original assets: initials generated from fictional names; landscape.svg written in this project; eight PCM tone files generated by scripts/media.ts; fictional script texts. Speech caches were generated through Edge and Windows speech engines, not copied from messaging applications. System fonts/emoji are referenced by name, never bundled. There are no WeChat notification sounds, logos or extracted proprietary icon/font files.

Release policy: distribute our source and required notices, not vendored runtime binaries. If a future installer bundles FFmpeg/Chromium/voices or dependencies, repeat the binary/source-offer/license review. Microsoft online speech and installed Windows voices remain subject to their service/platform terms. A v1 stable launch and broad commercial licensing claims are not approved by this audit.
